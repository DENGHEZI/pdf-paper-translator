# 踩坑清单（真实论文上验证过）

这些都是实际做 E1 / E5 / E7 / E9 / P01 / P02 / P03 / P05 八篇论文时踩出来的。
每条都给出**现象 → 原因 → 处理**。

## 一、图片抽取

### 1. 图注是窄块，被宽度阈值滤掉
- 现象：21 张图只抽出 16 张，缺的几张图注都是居中短句（`Figure 12: Sample Annotation...`，块宽仅 212pt）。
- 原因：图注宽度过滤设成了 `w > 250`。
- 处理：**图注宽度阈值降到 120**。图注普遍居中，比正文窄得多。

### 2. 正文段落被误判成图注
- 现象：`Figure 4 shows an exemplary visualization...`、`Figure 9 shows boxplots...` 这种**正文句子**被当成图注，导致区域算错。
- 原因：这些段落以 `Figure N` 开头，正则匹配成功。
- 处理：**看编号后面那个词的大小写**——图注是「说明」，正文是「动词」：
  ```python
  m = re.match(r"^\s*(?:Figure|Fig\.?|图)\s*(\d+)\s*([:：.])?\s*(.*)$", line, re.I)
  # "Figure 1: Schematic …"  → rest 大写 → 图注
  # "Figure 1 shows …"       → rest 小写 → 正文，丢弃
  # "Figure 4(A) is …"       → 无分隔符且以 "(" 开头 → 正文，丢弃
  ```
- ⚠️ **不要**用「块高 < 45pt」一刀切：很多期刊的图注有 3–5 行（50–80pt），
  在 P01 上这条规则把 13 张图漏成了 1 张。高度只用来挡掉超长块（`h < 120`）。

### 3. 图内文字与正文同字号，无法靠字号区分
- 现象：图表里的坐标轴标签、图例、子图标注都是 11pt，与正文一致。
- 处理：正文块判定用 **宽度 > 内容宽 × 0.70 且字符数 ≥ 80**；图内标签块要么窄、要么短。

### 4. 图跨页（图在上页底部，图注在下页顶部）
- 现象：`Figure 11` 的图注在 p20 顶部（y=74），同页上方没有图 → 区域高 < 40pt，被判“太矮”跳过。
- 处理：区域高度 < 40 时**回退到上一页**：
  ```
  上界 = 上一页“最后一张图 y0 之上的正文块底边”
  下界 = 上一页高度 - 20
  ```

### 5. 用「图形簇上溯」会吞掉正文
- 现象：`get_drawings()` 的矩形跨越正文区，向上聚类一直升到页顶，把正文段落裁进图里（验证方法：裁切区内最长文本行 > 110 字符）。
- 处理：**不要**只用 drawings 聚类。用「正文块底边 + 上一图注底边」作上界，drawings 只作辅助。

### 6. 图由上百个位图碎片拼成
- 现象：`len(page.get_images())` = 120，每片 43×77 到 1123×898，无法重组。
- 处理：放弃按碎片还原，改**按区域整页渲染** `page.get_pixmap(clip=rect, dpi=250)`。

### 7. 单页多图
- 处理：图注按 y 排序，`prev = 上一图注底边`，逐张推出上界。

### 8. 校验方法（必做）
```python
inner = page.get_text("text", clip=rect)
longest = max(len(x) for x in inner.splitlines())
# longest > 110 → 大概率混入正文
```
再统计非白像素占比（`< 3%` 可能是空白裁切）。

### 8b. 图注块的**首行是空行**
- 现象：P02 的 21 张图只抽出 13 张，缺 1–6、11、14；且日志里**没有任何警告**（说明图注压根没被识别）。
- 原因：排版把编号前的空行也算进了同一个 text block，`lines[0]` 是 `""`，图注文字在 `lines[1]`。
  ```python
  m = CAP_RE.match(lines[0])      # ✗ 全部落空
  ```
- 处理：**扫描块内任意一行**——
  ```python
  label = next((CAP_RE.match(ln).group(1) for ln in lines
                if ln and CAP_RE.match(ln)), None)
  ```
- 教训：`probe_pdf.py` / `extract_text.py` / `extract_figures.py` 三处都要用同一套判据，
  否则「探查说有 21 张图」但「抽图只出 13 张」，很难查。

### 8c. 跨页图的下界会裁进页脚页码
- 现象：跨页图 `y 472–822`，把页脚 “19” 也框进去了。
- 处理：底部先取 `page.height - 20`，再扫一遍页面底部 12% 区域里高度 <40pt 的文本块（页码/版权行），取 `min(bottom, 该块 y0 - 2)`。

### 8d. 栏数判断不要用「x0 是否有左右两簇」
- 现象：P02 明明是单栏，却被判成双栏——因为图表里的标签块落在右侧。
- 处理：看**最宽的那批文本块占页宽的比例**：单栏正文 ~0.75–0.85W，双栏单栏正文仅 ~0.40–0.48W。
  ```python
  median_wide < 0.55 * page_width   # → 双栏
  ```

## 二、参考文献

### 9. `(?<=[.)])` 后视断言导致整段切不开
- 现象：38 条参考文献只切出 1 条。
- 原因：第 1 条以 `... West Conshohocken, PA` 结尾（**无句点**），后面直接跟 `2. ASTM...`，后视断言不成立。
- 处理：改**纯前瞻** `\s(?=\d{1,2}\.\s+[A-Z])`，再过滤以 `^\d{1,2}\.` 开头的片段。
- 另一种坑：要求“首词后跟逗号”的正则（`[A-Z][a-z]+,`）会把 `7. Maintenance Guidebook...` 并进上一条。

### 10. 编号连续性自检
```python
nums = [int(re.match(r"^(\d{1,2})\.", r).group(1)) for r in refs]
assert nums == list(range(1, len(nums)+1))
```
不连续 = 切分或漏页。

## 三、双栏论文（原位模式）

### 11. 首页“标题+摘要”被合并成跨栏大块
- 现象：一个 block 的 bbox 横跨左右两栏（x 56–545），直接按块替换会串字。
- 处理：该块改用 `raw` 模式，按 span 级坐标逐段精确回填；或按 x 是否 < 栏分隔线拆成两块。

### 12. 粗体章节标题原块很窄
- 现象：`B. CNNs` 的 bbox 只有 40pt 宽，中文标题被缩到 0.66 倍。
- 处理：**粗体标题块扩展绘制宽度到整栏**（`x1 = min(栏右边界, x0 + 245)`）。

### 13. 混淆矩阵/结果表是真表格（带矢量边框）
- 现象：数字是文本 span，表头需译，但整块重绘会丢列对齐。
- 处理：`cells` 模式——按 span 文本精确映射替换并居中重绘，数字保留原文；或整表保留英文、只译表注。

## 四、原位 PDF 的技术要点

### 14. `fill=False` 是关键
```python
page.add_redact_annot(rect, fill=False)
page.apply_redactions(images=fitz.PDF_REDACT_IMAGE_NONE,
                      graphics=fitz.PDF_REDACT_LINE_ART_NONE,
                      text=fitz.PDF_REDACT_TEXT_REMOVE)
```
不刷白底 → 深色卡片上的白字替换后背景不受损；`IMAGE_NONE` / `LINE_ART_NONE` 保证图片与矢量图不被删。

### 15. 不要用 `insert_htmlbox` 排中文长句
MuPDF 的 HTML 引擎对纯 CJK 连续串断行不可靠，会溢出栏宽压到表格。
自己写 `wrap()`：CJK 单字成 token、连续 ASCII 词成 token、标点禁则（`，。、；：？！）】》` 不出现在行首），再用 `fitz.TextWriter` 逐行绘制。

### 16. 字体
- 正文 `simsun.ttc`（宋体），标题/加粗 `simhei.ttf`（黑体）。
- SimSun 缺 `ŷ ϕ ∆ ⊆ − ⊂ ∂ ∇` → 替换成 `y^ φ Δ ∈ -` 等。
- 体积会膨胀（TextWriter 重复嵌入字体）：`doc.subset_fonts()` + `save(garbage=4, clean=True)`。

## 五、Word 模式

### 17. 用户说“图片没保存”
- 现象：文字译完了，用户看不到图。
- 原因：PDF 里的图是位图碎片 / 矢量图，没内嵌进 docx。
- 处理：抽图 → `add_picture()` → **自检 `word/media/` 文件数 == 原文图数**，并把 PNG 另存一份到 `figures/` 供用户直接查看。

### 18. 宽表在 A4 竖排会挤
- 处理：列数 ≥ 10 时字号降到 7pt；必要时该节改横向（`section.orientation`）。

### 19. 预览器不渲染内嵌图
- 现象：docx 里明明有 12 张图，网页预览一片空白。
- 处理：告知用户用 Word/WPS 打开；或额外导出 PDF 供预览。

# v1.1 修复记录（在 5 篇真实论文上回归验证时发现）

这一轮的教训是：**单个脚本在单篇论文上跑通，不等于通用**。
把手工脚本改成通用脚本后，在 E9 / P01 / P02 / P03 / P05 上逐一回归，才暴露出下面这些问题。

### 20. 长图注被「块高 < 45pt」漏掉
- 现象：P01（13 图 + 附录 A1–A7）只抽出 1 张。
- 原因：P01 的图注是 3–5 行、高 50–80pt，被高度阈值全部挡掉。
- 处理：判据换成「编号后首词是否小写」（见上面第 2 条），高度上限放宽到 120pt 只做兜底。

### 21. `Figure 4(A) is increased by 0.2` 被当成图注
- 现象：P01 抽出 21 张，其中「图 4」出现两次，且顺序错乱（1,2,4,3,4,…）。
- 原因：无分隔符、后面紧跟 `(` 的正文引用也满足「Figure + 编号」。
- 处理：**无分隔符且 rest 以 `(` 开头 → 判为正文**。
  ```python
  if not sep and rest.startswith("("): return None
  ```

### 22. 双栏论文按整页宽裁图 → 裁进邻栏正文
- 现象：E9（IEEE 双栏）抽出的图右侧带着另一栏的文字。
- 原因：只按内容区整体 x 范围裁切，而图只占一栏。
- 处理：先判栏（见第 23 条），再**按图注中心落在哪一栏，裁该栏的 x 范围**。
  修复后 E9 的图宽从 483px 降到 420px（正好一栏），且 7/7 全出。

### 23. 栏数判断不能用「x0 是否有左右两簇」
- 现象：P02 单栏被判成双栏（图表里的标签块落在右侧）。
- 处理：看**最宽的那批文本块占页宽的比例**——单栏正文 ~0.75–0.85W，双栏单栏正文仅 ~0.40–0.48W。
  ```python
  median_wide < 0.55 * page_width   # → 双栏
  ```

### 24. 页边水印把内容区左界拉到 x=11
- 现象：E9 是 arXiv 预印本，页边竖排 `arXiv:2211.10062v1 [cs.CR]`，内容区左界算成 x=11，
  裁图左侧多出一条水印竖条。
- 处理：统计 x 坐标时**丢弃 `x < 页宽 × 5%`** 的块（页边水印/装订线），再用 3%/97% 分位。

### 25. 参考文献标题被 PDF 拆成 `R EFERENCES`
- 现象：E9 提取到 **0 条**参考文献。
- 原因：`\bReferences\b` 匹配不到带字间空格的 `R EFERENCES`（PDF 常见）。
- 处理：去掉所有空白后再比：
  ```python
  re.sub(r"\s+", "", line).lower() in ("references", "bibliography", "参考文献")
  ```

### 26. 参考文献里的 `vol. 97. PMLR` 被当成第 97 条
- 现象：E9 提取 44 条、编号却到 97，报「缺失 44–96」。
- 原因：「凡 `N. 大写` 就切」的正则会把 URL/卷号里的 `97. PMLR` 当成新条目。
- 处理：**按编号递增顺序提取**（1→2→3…，断号即停），天然免疫这类误切：
  ```python
  while True:
      m = re.search(r"(?:^|(?<=[\s.]))%d\.\s+(?=[A-Z])" % k, raw, pos)
      if not m: break
      ...
      k += 1
  ```

### 27. 无编号（作者—年份）参考文献无法按编号提取
- 现象：P01 的参考文献没有 `1.` / `[1]`，顺序提取直接报错。
- 处理：加第三种模式——**以 `X. Y. Surname,` 开头的行作为新条目起点**，其余为续行，
  并修复跨行连字符（行末 `-` + 下行小写首字母 → 拼接）。

### 28. 字母式二级标题 `A. Xxx` 与罗马数字一级标题 `I. Xxx` 冲突
- 现象：E9 的一级标题 `I. INTRODUCTION` 被 `[A-Z]\.\s+[A-Z]` 抢判成二级标题。
- 处理：**先判 h1（`1.` / `IV.`）再判 h2（`1.2` / `A.`）**。

### 29. 参考文献区的正文块被标成 body → 会被误译
- 现象：`References` 之后的大量条目仍标 `body`，按块清单翻译时容易顺手译掉。
- 处理：遇到 `refs_title` 后设置 `in_refs = True`，其后所有块一律标 `ref`。

# v1.2 修复记录（MDPI 单栏 20 页论文实战）

### 30. 正文块宽度小于「页宽 × 0.70」时，图区上界退化成页顶
- 现象：MDPI 论文正文块宽 394pt，页宽 595pt（0.66W），一条正文都没识别到，
  于是每张图都从页顶 y=57 开始裁，把上方整段正文都框进图里。
- 处理：正文判定改为**相对所在栏的内容宽度**（`w >= col_w * 0.72`），
  而不是相对页宽。单栏取内容宽，双栏取栏宽。

### 31. 图注标签被并进正文块的最后一行
- 现象：某页出现两个「图 3」，顺序错乱（1,2,4,3,4…）。
- 原因：该块的最后一行是 `Figure 3.`（正文段落末尾把图注标签吞进来了），
  而 `scan()` 遍历块内所有行去匹配图注。
- 处理：**只认首个非空行**。
  ```python
  first_line = next((ln for ln in lines if ln), "")
  label = match_caption(first_line)
  ```
  既兼容「首行为空」的图注块（P02），也排除「末行才是 Figure N」的正文块。

### 32. 图上方的表格被裁进图里
- 现象：图 4 的裁切区域包含了它上方的表 4（连表头一起进图），
  校验指标是「最长行 100 字符」——因为表格行文本很长。
- 处理：把**表注（`Table N.` 开头）与数字密集的表格行**也记为障碍物，
  图区上界取 `max(正文底边, 表格底边, 上一图注底边)`：
  ```python
  nums = re.findall(r"\d+(?:\.\d+)?", joined)
  is_table_row = w >= col_w*0.50 and len(nums) >= 4 and 20 <= len(joined) <= 600
  ```

### 33. 后置声明字段
- `back` 新增 `author_contributions`；`funding` / `declaration` 支持 `\n` 多行
  （伦理审查、知情同意、数据可得性、利益冲突各占一行）。

### 34. 横向页（/Rotate 90）让所有块变成「又窄又高」
- 现象：某篇 MDPI 论文有 2 页横向排版（`page.rotation == 90`），
  这两页上的文本块 bbox 宽只有 9–15pt、高 600+pt，图注被「宽 > 120」直接滤掉，
  8 张图只抽出 7 张，且无任何警告。
- 原因：`page.get_text("dict")` 返回的是**内容空间**坐标，横向页的文字在那里是竖的。
- 处理：把所有 bbox 用 `page.rotation_matrix` 映射到**显示空间**再判断；
  `get_pixmap(clip=rect)` 的 clip 本身就是显示坐标，所以渲染无需额外变换；
  反过来给 `get_text(clip=...)` 校验时要乘 `derotation_matrix`。
  ```python
  r = fitz.Rect(b["bbox"])
  if page.rotation:
      r = r * page.rotation_matrix
  ```
- 校验输出里会标 `[旋转]`，便于确认。

# v1.4 修复记录（ICLR 论文 + 左右并排图）

### 35. 左右并排的两张图被裁到一起
- 现象：ViT 论文 p7 上 Figure 3（左半 x108–294）与 Figure 4（右半 x308–494）并排，
  两条图注 y 相同。按整栏宽裁切会把两张图裁进同一张。
- 处理：新增 `figure_x_range()`——取 `[top, cy0]` 竖带内、**与图注 x 范围有水平重叠**的
  图形/图像，求其 x 外接框；并排的另一张因无重叠被自动排除。
- 配套：图注 y 区间重叠时（`abs(cy0 − prev_top) < 60`）不把上一图注底边当作本图上界，
  否则第二张图会被压成 0 高度。

### 36. 正文里的 “… as seen in Figure 6.” 被当成图注
- 现象：P01 出现 8 张重复图，裁切区最长行 89–96 字符（明显是正文）。
- 原因：行内搜索 `Figure N` 太宽松。
- 处理：行内匹配（offset < 40）**只允许前缀是纯子图标签**（`a.` / `(b)` / `1.`），
  正则收紧为 `^(\([A-Za-z0-9]{1,2}\)|[A-Za-z0-9]{1,2}[.)])$`——
  否则 `in`（2 字母单词）也会被当成标签。

### 37. 图注块首行是空行 / 图注与子图标签同块
- 现象 A：P02 的图注块 `lines[0] == ""`，只看首行会全部漏检。
- 现象 B：P02 的图注实际在 `a. b. c. d. Figure 3: Sample images…` 里，不在行首。
- 处理：先剔除空行得到 `body_lines`；首行做「行首匹配 → 行内前 40 字符匹配」；
  其后各行仅当**前面全是子图标签**时才允许匹配。

### 38. 作者—年份（全名）参考文献：ICLR/NeurIPS 风格
- 现象：ViT 的参考文献无编号、作者用全名（`Samira Abnar and Willem Zuidema. …`），
  既不是 `[N]` 也不是 `N.`，`extract_unnumbered` 的「姓名缩写」模式只切出 1 条。
- 处理：新增 `extract_by_year()`——这类条目几乎都以年份结尾，按「年份 + 句点」收尾来切。
  ```python
  if re.search(r"(?:19|20)\d{2}[a-z]?\.\s*$", cur): entries.append(cur); cur = ""
  ```
- 两个附带坑：
  a) **风格判定要只看开头 3000 字符**，否则文末附录里的 `1. Training resolution is 224.`
     会把风格误判成 `N.`；
  b) **末尾残留要丢弃**——最后一段未闭合文本常是附录表格，若不含年份则不收；
     页眉 `Published as a conference paper at ICLR 2021` 也要过滤。

### 39. docx 写入报 “no NULL bytes or control characters”
- 现象：`ValueError: All strings must be XML compatible`。
- 原因：PDF 抽取带进了 `\x10` 之类的控制字符。
- 处理：`build_docx.py` 统一加 `clean()` 清洗 `[\x00-\x08\x0b\x0c\x0e-\x1f]`。

### 40. 附录需要排在参考文献之后

# v1.5 修复记录（Elsevier 混合版式：通栏图 + 双栏正文）

### 41. 页眉被当成「通栏正文」，导致双栏被误判为单栏
- 现象：Elsevier 双栏论文被判成单栏，图区按整页宽裁切。
- 原因：每页页眉 `L. Cao et al.`（宽 463pt）跨过中线，被计入「通栏宽块」，
  页数一多就超过 3 条 → 判定单栏。
- 处理：栏数判定与聚类时**跳过页眉/页脚**（`y1 < 55` 或 `y0 > 页高 − 45`）。

### 42. 通栏插图的上方正文被裁进图里
- 现象：图 5（通栏照片）的裁切区从上一图注底边开始，把左栏两段正文（y245–321）框进去了，
  校验指标「最长行 59 字符」暴露问题。
- 原因：正文在左栏（宽 253pt），而 `col_w` 被算成整页 526pt，
  `w >= col_w*0.72` 判不出这些正文块，于是 `top` 退化成上一图注底边。
- 处理：**位图型插图直接从该位图顶端开始**——取与本图横范围重叠、
  且位于上一图注下方的位图，用其最小 `y0` 作为上界：
  ```python
  if imgs_here:
      top = max(top, min(r.y0 for r in imgs_here) - 4)
  ```
  对多图拼成的图（如 21 张注意力图）取 min y0 正好是整图顶端，不会切掉。
